# Security Policy

## Supported versions

This project is experimental. Security fixes are applied to the latest
published version only.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Instead, use
[GitHub's private vulnerability reporting](https://github.com/beetlio/connect/security/advisories/new)
or email [info@beetl.io](mailto:info@beetl.io).

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Reports and reporter identities will be kept private while the
issue is investigated and a coordinated fix is prepared.
